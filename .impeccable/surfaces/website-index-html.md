# Surface brief: public landing page (website/index.html) and its docs skin

Scope: the landing page at the root of GitHub Pages, plus the MkDocs Material skin under /docs/ that inherits its world.
Visitor mode: Persuade (landing); Read (docs).

Audience: busy professionals on a Mac whose Gmail is a second job. Job: decide in seconds whether this calms the inbox
without an opaque, expensive agent. Action: watch the film / try the demo, then run the setup script.
Proof: the real runner.py run on a synthetic mailbox (counts, tasks, model calls), screenshots of that run, the EN/FR film.
Constraints: every name and message is synthetic and labelled so; no invented users, costs or accuracy numbers.

## Direction contract

THESIS: The inbox is a metro network. Mail rides one line from the INBOX terminus through Rules, Sweep and Classify stations
and alights at twelve AI/ tag terminals; the model is an express spur lit only when rules cannot route. Refuses the
gradient-hero-with-floating-email-cards SaaS page.

OWN-WORLD: Off-white enamel ground (#f4f2ec), signage black (#121417), twelve line colours, one per tag, on flat enamel
panels with rounded-rect station signs and roundel station marks; thick 8px line strokes with 45-degree bends only.
Signal red is reserved for Action and "waiting for you". Barlow Semi Condensed for signage, Atkinson Hyperlegible for
reading, JetBrains Mono only for commands and data. Raises: label changes snap like a destination blind (from Depot
Blind); signal red reserved (from Neon); every number is a demo readout that cross-checks (from Six-Pack); quiet hours
leave the express spur dark (from Plankton).

STORY: The visitor sees their own mess routed, understands rules first / model last, believes nothing moves without
consent, and runs the setup script or watches the film.

FIRST VIEWPORT: Left 5/12, a black enamel sign with the headline "Every message, routed." and lead line, primary station
sign "Install on macOS" plus "Watch the film". Right 7/12, the live line diagram: messages travel from INBOX and peel off
to tag terminals; the express spur to Classify lights for two ambiguous messages; a platform board beneath reads the
run's counts.

FORM: Transit line map, position 5 of my ordered list; seed key 31f3b8e3.
